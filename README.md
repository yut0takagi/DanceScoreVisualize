# ダンススコア可視化プラットフォーム：ビジネス要件定義キャンバス

## 1. ビジョン / 目的

ダンサーや初心者が、プロの動きを「定量的に」学び、上達を可視化できる世界を実現する。AIによる骨格・動作解析で、感覚的な練習からデータドリブンな練習へ転換する。

---

## 2. ターゲットユーザー

| セグメント          | 課題                  | 提供価値                       |
| -------------- | ------------------- | -------------------------- |
| 一般ダンサー（学生・社会人） | 鏡や感覚に頼った練習で上達が見えにくい | 骨格比較・スコア・具体的アドバイスで「上達を数値化」 |
| プロ志向ダンサー       | 技術分析を客観的に行いたい       | フォーム・タイミング・エネルギーを定量評価      |
| ダンススクール運営者     | 生徒ごとの成長管理が属人的       | クラス別スコアとレポートでコーチング効率化      |
| イベント・コンテスト運営   | 公平な審査指標を求める         | 客観的スコア化による公正な審査支援          |

---

## 3. 提供価値（Value Proposition）

* **スコア×可視化**：姿勢・タイミング・キレの3軸スコアで上達を定量化。
* **骨格ヒートマップ**：誤差箇所を色で可視化、直感的に理解可能。
* **AIアドバイス生成**：不足動作・ズレ箇所を自然言語でフィードバック。
* **比較機能**：プロ動画との重ね再生・同期再生。

---

## 4. ビジネスモデル

| 区分        | 内容                       | 収益源                |
| --------- | ------------------------ | ------------------ |
| B2C（月額）   | 個人ユーザーが動画をアップロードし解析      | サブスクリプション（月¥980〜）  |
| B2B（SaaS） | ダンススクールやスタジオに管理ダッシュボード提供 | ライセンス契約（月¥10,000〜） |
| B2E（イベント） | コンテストや大会でのスコアリング利用       | イベント利用料（回数課金）      |
| B2G（教育連携） | 学校教育や部活動への導入             | 教育機関向けパッケージ        |

---

## 5. 機能要件

### MVPフェーズ（Phase 1）

* 2D骨格推定（MoveNet / MediaPipe）
* 動画比較・角度差スコア化（フォーム・タイミング）
* レーダーチャート・ヒートマップ表示
* AIコメント生成（簡易ルールベース）

### Phase 2

* 音源同期（librosaで拍情報取得）
* DTWによる時系列整列
* 3D姿勢推定（VideoPose3D）
* 学習ログ・スコア履歴管理

### Phase 3

* AIコーチモード（目標提示＋改善提案）
* ジャンル別分析（HIPHOP, Jazz, K-POPなど）
* ダンススクール向け生徒管理ダッシュボード

## 6. 技術構成

| 層       | 使用技術                                                      |
| ------- | --------------------------------------------------------- |
| フロントエンド | React / Next.js + TailwindCSS（Web）, React Native（モバイル）    |
| バックエンド  | FastAPI + Python (OpenCV, NumPy, SciPy, fastdtw, librosa) |
| モデル     | MoveNet, MediaPipe, VideoPose3D                           |
| DB      | PostgreSQL（ユーザー・動画・スコア）                                   |
| ストレージ   | Firebase Storage / AWS S3                                 |
| デプロイ    | Railway / Render（API） + Firebase Hosting（Web）             |

---

## 7. KPI・成功指標

* アクティブユーザー数（MAU）
* 動画アップロード回数 / 日
* 平均スコア改善率（初回→N回後）
* 有料転換率（Trial → Paid）
* 学習継続率（7日・30日）

## 8. 競合・差別化ポイント

| 競合                    | 特徴             | 当社優位性                |

## 9. 将来展開（3年ロードマップ）

1. **Year 1：MVP構築・β版リリース**
   → 個人練習用Webアプリ
2. **Year 2：商用展開・提携スクール導入**
   → B2B SaaS拡張・講師向け管理UI
3. **Year 3：国際展開 / ダンスコンテスト公式採用**
   → AI審査補助システム・公式API化

## 10. リスクと対応

| リスク       | 対策                    |
| --------- | --------------------- |
| 骨格推定精度が低い | 撮影ガイド提供＋フィルタリングアルゴリズム |
| プライバシー懸念  | 動画の自動匿名化・骨格情報のみ保存     |
| 著作権・肖像権   | 公開動画の利用制限・同意フォーム運用    |
| モデル処理コスト  | 軽量モデル導入＋バッチ処理設計       |
